# 文档索引

本目录存放 `occt-draw-web` 的中文工程文档。当前项目方向是浏览器中的三维云端 CAD 工作台。

## 当前有效文档

1. [开发上下文交接](./开发上下文交接.md)

    给新对话、新工具或新开发者快速了解当前项目状态、包边界、当前能力和协作习惯。

2. [文档编辑事务架构重构方案](./文档编辑事务架构重构方案.md)

    说明下一阶段文档编辑事务体系的重构目标，包括 `DocumentEditor`、`Request`、`MutationScope`、`DocumentWriteContext`、自动 change 记录和 transaction 生成。

3. [math 包架构设计](./math包架构设计.md)

    说明 `@occt-draw/math` 当前职责、2D/3D 几何分层、曲线采样能力和后续采样策略演进方向。

## 历史文档说明

部分旧总览文档已经不再作为当前实现依据。当前实现状态优先参考代码、`开发上下文交接.md` 和新的专项架构文档。

## 维护规则

- 文档统一使用中文。
- 新增设计决策时同步更新本文。
- 旧阶段内容不要继续作为当前实现依据。
- 当前实现状态优先以代码和 `开发上下文交接.md` 为准。
- 架构演进方案优先沉淀到独立文档，避免混入过期总览。
- 代码中的类型名、变量名、函数名和包名保持英文。
