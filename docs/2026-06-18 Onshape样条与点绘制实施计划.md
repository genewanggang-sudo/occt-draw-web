# Onshape 样条与点绘制调试记录及实施计划

日期：2026-06-18

## 1. Chrome 调试结论

调试对象：Onshape Part Studio 草图编辑状态，中文界面。

### Point

Onshape 行为：

- 工具栏图标为单点，tooltip 显示 `点 (shift+s)`，说明为“向草图中添加点”。
- 激活后，在草图平面单击一次即创建一个独立草图点。
- 创建后工具保持激活，可连续点击创建多个点。
- 点显示为蓝色小圆点，可被选择、约束、作为其他草图实体的引用。
- 没有观察到首版必须依赖的数值输入流程。

对本项目的含义：

- Point 首版应实现为最小闭环：点击投影到当前草图平面，提交一个 DocumentRequest，创建一个独立 `Point2D`。
- `SketchPrimitiveBuilder.addPoint(...)` 已存在，可直接复用。
- 不需要新增几何曲线类型。
- 首版不做尺寸输入、约束推理、点样式分类、构造点开关。

### Spline

Onshape 行为：

- 工具栏 tooltip 显示 `样条`，说明为“绘制多点曲线的草图，沿其长度拖动任意点以进行调整”。
- 激活后，第一次点击创建起点，后续每次点击追加一个样条点。
- 创建过程中，已确认的样条点显示为小点；鼠标移动时，从最后一个点到当前鼠标位置显示实时预览曲线。
- 双击当前点结束样条。
- 结束后工具保持激活，可继续创建下一条样条。
- 结束后的样条显示蓝色插值点，并显示白色圆形切向手柄；切向手柄可用于后续调整曲线形状。
- 观察到的 Onshape 样条更接近“fit/interpolation spline”：用户点击的点在曲线上，白色手柄属于后续编辑控制，不是首版绘制必需输入。

对本项目的含义：

- 首版应采用 `fitPoints` 作为用户输入状态，而不是要求用户直接输入 B-spline control points。
- 内部正式曲线可以保存为 `SketchSpline2D`，包含 `fitPoints`，并缓存/派生 `BSpline2` 用于采样显示。
- 首版只做绘制与显示，不实现白色 tangent handle 编辑；但数据结构需要预留 `handles` 或 `tangentControls` 扩展位置，避免后续返工。
- 双击结束、Esc 取消当前正在绘制的样条、完成后保持当前工具，是应对齐 Onshape 的交互行为。

## 2. 当前项目结构评估

### 已有基础

- `packages/math`
    - 已有 `BSpline2` 和 `Nurbs2`，支持 control points、degree、knots、`pointAt()` 和采样基础。
    - 缺少表达“用户点击的点在曲线上”的高层 spline 曲线抽象。现有 `BSpline2` 是底层 control-point 曲线，不应直接承担 Onshape 风格 fit spline 的交互语义。

- `packages/sketch`
    - 已有 `Point2D`、点 store、`SketchPrimitiveBuilder.addPoint(...)`。
    - `Curve2DSnapshot` 目前只包含 line、circle、ellipse、arc、elliptical-arc、conic，没有 spline。
    - `sampleSketchCurveSegments(...)` 尚不支持 spline。
    - `SketchDisplayBuilder` 已通过采样曲线输出显示线段，适合接入 spline。

- `packages/cad-model`
    - 已有 `SketchDocumentRequest` 模式。
    - 适合新增 `AddSketchPointRequest` 和 `AddFitSplineRequest`，保持通过 `target.primitives` 写入草图。

- `packages/editor`
    - 已有多阶段草图命令模式，例如 3 点圆、圆弧、圆锥、椭圆弧。
    - 适合新增 `SketchPointCommand` 和 `SketchSplineCommand`。

- `apps/web`
    - `CommandToolbar.tsx` 已有草图工具分组。
    - 只需新增 Point 与 Spline 工具入口。

### 前置问题

Spline 不是单包内部功能，必须跨 `math`、`sketch`、`cad-model`、`editor`、`apps/web` 实施。Point 虽然底层模型已存在，但也需要跨 `cad-model`、`editor`、`apps/web` 暴露绘制命令。

本计划不需要新增 package 依赖，不改变 package 依赖关系，不移动包目录。

### 架构原则

- `packages/math` 必须提供稳定几何对象和数值语义。允许存在内部纯函数，但 public API 不应以零散 helper 为主。
- `FitSpline2` 是 Onshape 风格样条的核心抽象：它表达“通过用户 fit points 的曲线”。`BSpline2` 是底层 basis curve：它表达“由 control points、knots、degree 定义的曲线”。两者不是同一个概念。
- `packages/sketch` 保存 CAD 草图语义和可编辑状态，例如 fit points、端点 vertex、edge role；不保存采样线段，不实现插值算法。
- `packages/cad-model` 只表达文档编辑请求和事务边界；不直接操作 raw sketch，不做数学求解。
- `packages/editor` 只负责交互状态机和 preview 生命周期；不拥有 spline 插值算法，不持久化派生几何。
- `apps/web` 只暴露工具入口；不承载命令语义或几何计算。
- 首版可以暂不实现 tangent handles，但数据模型必须预留切向控制扩展点；否则后续要重做 snapshot、编辑命令和选择模型。

## 3. 包职责与改动边界

### packages/math

新增：

- `FitSpline2` 或 `InterpolatedSpline2` 曲线类，继承 `Curve2`。
- 输入类型 `FitSpline2Input`：
    - `fitPoints: readonly Vector2[]`
    - `degree?: 1 | 2 | 3`
    - `closed?: boolean`
    - `startTangent?: Vector2`
    - `endTangent?: Vector2`
    - `parameterization?: 'chord-length' | 'centripetal' | 'uniform'`
- 输出/状态类型：
    - `FitSpline2ConstructionStatus`
    - `FitSpline2ConstructionOptions`
- 类能力：
    - `pointAt(parameter)`
    - `tangentAt(parameter)`
    - `isValid()`
    - `bounds()`
    - `sample(...)`
    - `toBSpline()` 或 `basisCurve`，用于暴露内部派生的 `BSpline2`，但不要求上层直接理解 knots/control points。
- 静态构造入口：
    - `FitSpline2.fromFitPoints(input): GeometryResult<FitSpline2>`
    - `FitSpline2.tryCreate(input): FitSpline2 | null`

修改：

- `geometry-2d/index.ts` 和 `math/src/index.ts` 导出新的曲线类与类型。
- `sampleCurveSegments2(...)` 无需新增特殊分支，只要 `FitSpline2` 继承 `Curve2` 并正确实现 `pointAt/tangentAt/domain` 即可复用现有采样框架。

原因：

- `packages/math` 的职责是提供稳定的几何语义和数值行为，不是向上层暴露一组临时 helper。
- Onshape 的 Spline 语义是 fit/interpolation spline：用户点在曲线上；而 `BSpline2` 语义是 control points 通常不在曲线上。两者必须在 math 层区分。
- 上层 editor、sketch、display 都应该依赖 `FitSpline2` 这个曲线抽象，而不是各自调用零散函数拼出采样点。
- 后续如果内部算法从 Catmull-Rom、三次 Hermite、全局 B-spline interpolation 切换到更严谨的 CAD 算法，public API 不应变化。

影响范围：

- 新增 `Curve2` 子类和类型导出，不改变现有 `BSpline2/Nurbs2` 行为。
- 不新增 package 依赖。

算法边界：

- 首版不应把“临时 polyline 平滑”作为正式数学模型。
- 推荐以 `FitSpline2` 表达用户意图，再由内部策略生成可求值曲线：
    - 2 个点：可作为退化的一次 fit spline 或返回退化，需在实施前固定策略。
    - 3 个点：支持二次或三次插值。
    - 4 个及以上点：默认使用 centripetal parameterization，降低自交和过冲概率。
- 初始实现可以先选择一种稳定算法，但算法必须封装在 `FitSpline2` 内部；不得让 `packages/editor` 或 `packages/sketch` 持有算法细节。

### packages/sketch

新增：

- `Spline2D` 曲线模型，语义上表示 sketch 中的 fit spline，而不是裸 `BSpline2D`。
- `Spline2DSnapshot`。
- `SketchPrimitiveBuilder.addSketchPoint(position)`，作为 `addPoint(...)` 的语义化 public API，可内部复用现有实现。
- `SketchPrimitiveBuilder.addFitSpline(points, options)`。

修改：

- `Curve2DSnapshot` 增加 `kind: 'spline'`。
- `curveFromSnapshot(...)` 支持 spline。
- `sampleSketchCurveSegments(...)` 支持 spline。
- `SketchDisplayBuilder` 无需特殊逻辑，只要 sampling 支持 spline 即可显示。
- `SketchPropertyValue` 需要支持结构化数组，或为 spline 引入明确的 `FitPointList` 属性值。不能把点列序列化成字符串。
- `Spline2D` 内部应按 sketch 语义保存：
    - `fitPoints`
    - `degree`
    - `closed`
    - `startTangent/endTangent` 可选预留
    - `parameterization`
- `Spline2D` 不应持久化派生出来的 sampled polyline；display sampling 是渲染层派生数据。

原因：

- Spline 是正式 sketch curve，不能用临时 polyline 代替，否则后续编辑、约束、尺寸、导入导出都会返工。
- Onshape 结束后显示的是可编辑 fit points 和 tangent handles，因此 sketch 层必须保存用户可编辑的 spline 定义，而不是只保存 math 计算后的 control polygon。

影响范围：

- 新增一种 public sketch curve snapshot。
- 需要确认所有 `Curve2DSnapshot` switch/分支的穷尽性。

边界：

- `packages/sketch` 负责持久化 sketch entity 语义和拓扑连接，不负责决定 spline 插值算法。
- `Spline2D` 可在 getter 中构造 `FitSpline2` 或缓存派生 `FitSpline2`，但缓存不进入 snapshot。
- 如果后续引入 tangent handle 编辑，只改 `Spline2DSnapshot` 的 optional controls 和 editor 操作，不需要重写 curve kind。

### packages/cad-model

新增：

- `AddSketchPointRequest` / `AddSketchPointRequestResult`。
- `AddFitSplineRequest` / `AddFitSplineRequestResult`。

修改：

- `src/index.ts` 导出 request 和 result type。

约束：

- Request 只能通过 `target.primitives.addSketchPoint(...)`、`target.primitives.addFitSpline(...)` 修改草图。
- Request 不直接操作 raw `Sketch`。
- Request 输入应保留完整用户意图：
    - `fitPoints`
    - `degree`
    - `closed`
    - `parameterization`
    - optional tangent controls
- Request result 应返回创建的 `curveId`、`edgeId`、`startVertexId/endVertexId`，以及 `payloadId`。

原因：

- 保持 undo/redo、preview、change recorder、document transaction 机制一致。
- cad-model 只表达文档级编辑意图，不应包含 fit spline 数学求解逻辑。

影响范围：

- 新增 public cad-model Request 类型。

拓扑决策：

- Point：创建独立 `Point2D`，不创建 vertex/edge，除非未来约束系统需要把 free point 映射成 vertex-like selectable entity。
- Spline：作为 open bounded curve，应创建一条 edge，并创建 start/end vertices 连接到首尾 fit point。
- 这样与现有 arc/conic 这类 open curve 保持一致，也为后续 profile、trim、约束选择提供稳定拓扑入口。

### packages/editor

新增：

- command id：
    - `sketch-point`
    - `sketch-spline`
- tool state：
    - `{ kind: 'point' }`
    - `{ kind: 'spline'; points: readonly Vector2[] }`
- `SketchPointCommand`
- `SketchSplineCommand`

修改：

- `CommandId` union。
- `CommandAvailabilityContext.activeSketchTool` union。
- `commandDefinitions`、`evaluateCommandAvailabilityMap(...)`。
- `Application.ts` 注册命令。
- `workbenchViewModel.ts` 增加工具 label。
- `index.ts` 导出命令。

Point 交互：

- 点击创建点。
- 创建后保持 point 工具。
- Esc 回到 select。
- 预览可不做，最多显示 hover draft point。

Spline 交互：

- 第一次点击设置第一个 fit point。
- 第二次点击追加点，并开始显示曲线 preview。
- 鼠标移动时使用 `fitPoints + currentPoint` 生成 preview。
- 双击当前点结束并提交 request。
- 至少 3 个点才允许提交首版 spline。2 点场景应提示继续添加点，不自动创建线段，避免 spline 命令和 line 命令语义混淆。
- Esc 行为：
    - 有 pending points 时清空 points，保留 spline 工具。
    - 无 pending points 时回到 select。
- 完成后保留 spline 工具并清空 points。
- preview 只能调用 `FitSpline2.fromFitPoints(...)`，不能在 editor 内实现插值算法。
- editor state 保存交互中的 pending `fitPoints`，不保存 derived `BSpline2`、knots 或 sampled segments。

原因：

- 与 Onshape 的连续绘制、双击结束、工具保持激活一致。
- editor 负责交互状态机，不负责几何内核。

影响范围：

- 新增 editor public command id 与 tool kind。

### apps/web

修改：

- `CommandToolbar.tsx` 新增工具入口：
    - Spline 放在曲线/绘制组，使用已有或新增 `ToolbarIconId.Spline`。
    - Point 放在绘制组或单点工具组，使用已有或新增 `ToolbarIconId.Point`。

可能新增：

- 如果 `packages/ui` 中没有 Spline/Point 图标，需要新增 icon id 和 SVG symbol。

原因：

- 让功能从 toolbar 可达。

影响范围：

- 不增加数值输入 UI，不增加 viewport dynamic input。

### packages/ui

仅当现有图标不足时新增：

- `ToolbarIconId.Spline`
- `ToolbarIconId.Point`
- 对应 `toolbar-icons.svg` symbol。

原因：

- 避免 web 使用错误或复用不准确图标。

影响范围：

- 新增 public icon id，不改变现有 icon。

## 4. 首版实施顺序

1. Point 链路先实施
    - cad-model request、editor command、toolbar 入口。
    - 因为 sketch builder 已有 `addPoint(...)`，风险低，可作为命令链路验证样板。
    - 同时补 `addSketchPoint(...)` 语义化 builder API，避免 editor/cad-model 直接依赖底层点实现细节。

2. Spline math 曲线抽象
    - 新增 `FitSpline2`/`InterpolatedSpline2`，继承 `Curve2`。
    - 固定 public 输入语义为 `fitPoints`，不是 control points。
    - 内部生成可求值曲线，可派生 `BSpline2`，但上层不依赖 knots/control points。
    - 对退化输入返回 `GeometryResult.empty()` 或 `GeometryResult.degenerate()`，不抛常规异常。

3. Spline sketch curve model
    - 新增 snapshot、model、fromSnapshot、sampling。
    - 正式模型保存 spline，不保存 preview polyline。
    - snapshot 保存 `fitPoints` 和 spline 语义参数，不保存 sampled segments。

4. Spline request 和 builder
    - `addFitSpline(points, options)` 生成一个 spline curve。
    - Spline 首版作为 open edge：创建 start/end vertices 和一条 edge。
    - 不创建额外控制点实体；fit points 保存在 spline curve snapshot 中。后续如果需要单独选择/约束每个 fit point，再引入 sub-entity 或控制点编辑模型。

5. Spline editor command
    - 支持 click add point、move preview、double click commit、Esc 分层取消。
    - preview 使用 `FitSpline2` 正式曲线抽象。

6. web toolbar
    - 增加 Spline 与 Point 工具。

7. ui icon
    - 若已有 Spline/Point 图标，直接复用。
    - 若没有，新增 `ToolbarIconId.Spline` 和 `ToolbarIconId.Point`，这是明确 public UI API 变更，不应在 web 内临时复用错误图标。

## 5. 不进入首版的能力

- Spline tangent handle 编辑。
- Spline point 插入/删除。
- 闭合 spline。
- 曲率梳或曲率颜色图。
- 尺寸输入、表达式输入。
- 自动约束推理。
- 点/样条的 construction 模式。
- Spline 与已有几何的吸附/约束。
- 文本、Slot、Trim、Offset 等其他 Onshape 草图工具。

## 6. 测试计划

### Point

- `AddSketchPointRequest` 创建一个 `Point2D`。
- undo/redo 能撤销和恢复点。
- Point command 在非 sketch 状态 disabled，在 sketch 状态 enabled。
- 点击创建点后仍停留在 point 工具。

### Spline

- `FitSpline2.fromFitPoints(...)` 对少于 3 个点、非有限坐标返回空或退化结果。
- 3 个以上 fit points 构造 `FitSpline2` 成功，`isValid()` 为 true。
- `FitSpline2.pointAt(...)`、`tangentAt(...)`、`sample(...)` 返回有限结果。
- `FitSpline2` 在默认 parameterization 下点序稳定，重复构造结果一致。
- `Spline2D.snapshot()` 可 round-trip。
- `curveFromSnapshot(...)` 可恢复 spline。
- `sampleSketchCurveSegments(...)` 对 spline 返回有限线段。
- `AddFitSplineRequest` 创建一条 spline curve 和 open edge。
- 创建结果包含 start/end vertices，不创建额外 sampled polyline entity。
- undo/redo 能完整撤销和恢复。
- editor preview 与提交结果共用 `FitSpline2` 曲线抽象。
- 双击结束后保留 spline 工具。
- Esc 第一层取消 pending points，第二层回 select。
