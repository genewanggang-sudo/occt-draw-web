# 视口运行时依赖规则

渲染相关包按以下方向收敛：

```txt
webgl-engine -> math
cad-rendering -> webgl-engine, cad-model, sketch, core, math
editor -> cad-rendering, webgl-engine, cad-model, sketch, core, math
apps/web -> editor, ui
```

规则说明：

- `apps/web` 只提供 React shell 和 viewport host HTMLElement，不创建 canvas，不持有 `RenderEngine`。
- `EditorViewportRuntime` 负责创建 canvas、绑定输入事件、维护 ViewCube、调用 `cad-rendering` 生成 RenderGraph，并驱动 `webgl-engine`。
- `cad-rendering` 是 CAD 业务显示层，不接触 DOM，不处理输入事件。
- `webgl-engine` 是底层通用渲染引擎，不依赖任何 CAD 业务包。
