# 待优化问题记录

1. 刷新页面时，中间画布会闪一下，且整块呈蓝色。
2. 刷新页面 -> 移动或旋转一下 -> 点击基准面 -> 点击进入 Sketch 后，基准面和新增草图面的渲染存在问题，需要确认。
3. 绘制 3 点圆弧时，预览状态和确定后的颜色一样；Onshape 使用两种不同颜色。当前实现中，预览时线较粗、点较大，确定后点变小、线变细，与 Onshape 效果不一致，需要调试 Onshape 确认实现后再考虑当前实现如何修改。
4. 完成草图后，草图面显示消失没有问题，但草图中绘制的线颜色没有变化；需要查看 Onshape 中完成草图后的显示方式，并作为一个需要修改的点。
5. 绘制中点线时，预览和确认后的效果与 Onshape 不一致；当前可能是数据层和渲染层都未完善，需要思考如何完善该功能。
