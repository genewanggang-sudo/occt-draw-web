# 草图系统架构设计

## 目标

草图系统是参数化建模的前置编辑层，负责在工作平面上创建、编辑和解析二维几何，并为后续拉伸、旋转、切除等特征提供稳定的截面输入。

本文档作为中期实现方案指导，覆盖从当前“基准面建草图 + 直线绘制”到“可编辑草图 + 封闭区识别 + 特征引用”的实现边界。本文档不设计 B-Rep、布尔、倒角、圆角等几何内核能力，这些能力仍由 Wasm/OCCT 侧承担。

## 核心原则

- `sketch` 包表达草图业务语义，不把草图对象放进 `math`。
- `math` 只提供通用二维几何、坐标系、查询、采样和容差能力。
- 草图实体保存用户创建的基础几何，封闭区 Profile 是计算结果，不作为用户直接编辑的主数据。
- 特征不能直接引用临时 Profile id，必须保存可重算、可匹配的 Profile 选择引用。
- 草图编辑命令属于 `editor`，草图数据模型和解析能力属于 `sketch`。
- `cad-rendering` 可以理解草图业务语义，并把草图实体、临时预览和 Profile 高亮投影为 `RenderScene`。
- `webgl-engine` 不知道草图、特征、命令，只消费通用渲染节点和拾取输入。

## 包边界

```txt
math
  通用 Vec2 / Plane3 / LineSegment2 / Polygon2 / Intersection / Distance / Containment

core
  CadDocument / PartStudio / Feature / DocumentOperation / ReferencePlaneObject

sketch
  Sketch / SketchEntity / SketchProfile / SketchProfileResolver / SketchProfileSelection

constraints
  后续约束和尺寸求解，依赖 sketch，不反向污染 sketch 基础模型

editor
  SketchCommand / SketchLineCommand / 后续草图选择、删除、移动、工具命令

cad-rendering
  Sketch + Profile + Draft -> RenderScene

webgl-engine
  渲染、拾取、相机、ViewCube，不包含草图业务语义
```

## 数据模型

### Sketch

`Sketch` 是附着在一个工作平面上的二维编辑容器。

```ts
interface Sketch {
    readonly id: SketchId;
    readonly name: string;
    readonly planeRef: string;
    readonly planeKind: ReferencePlaneKind;
    readonly entities: readonly SketchEntity[];
}
```

`planeKind` 只作为业务文案和默认基准面标识，真实坐标转换必须通过 `ReferencePlaneObject -> Plane3`。

### SketchEntity

第一阶段保留最小实体：

```ts
type SketchEntity = SketchPoint | SketchLine;

interface SketchPoint {
    readonly id: SketchEntityId;
    readonly kind: 'point';
    readonly x: number;
    readonly y: number;
}

interface SketchLine {
    readonly id: SketchEntityId;
    readonly kind: 'line';
    readonly startPointId: SketchEntityId;
    readonly endPointId: SketchEntityId;
}
```

中期扩展实体：

- `SketchCircle`
- `SketchArc`
- `SketchPolyline`
- `SketchSpline`
- `SketchConstructionGeometry`
- `SketchDimension`
- `SketchConstraint`

曲线实体进入 Profile 计算时，应先通过 `math` 的曲线采样或解析能力转换成可参与平面图计算的边。第一版 Profile Resolver 只支持直线。

## 坐标系

草图内部所有几何都使用二维局部坐标。

- 创建和编辑草图点时，屏幕点先通过 `screenPointToWorldRay` 得到世界射线。
- 世界射线与 `Plane3` 求交。
- 交点通过 `Plane3.projectPointToLocal` 转为草图二维坐标。
- 显示时通过 `Plane3.localToWorld` 转回世界坐标。

草图包不保存三维点作为实体主数据。三维显示和特征建模需要时由草图平面和二维实体派生。

## Profile 与封闭区

Profile 是草图实体计算出来的封闭区域，用于后续特征建模。Profile 不是用户直接创建的持久实体。

```ts
interface SketchProfile {
    readonly id: SketchProfileId;
    readonly sketchId: SketchId;
    readonly outerLoop: SketchLoop;
    readonly innerLoops: readonly SketchLoop[];
    readonly area: number;
    readonly centroid: Vec2;
    readonly bounds: BBox2;
}

interface SketchLoop {
    readonly id: SketchLoopId;
    readonly edges: readonly SketchProfileEdge[];
    readonly signedArea: number;
    readonly winding: 'clockwise' | 'counter-clockwise';
}

interface SketchProfileEdge {
    readonly entityId: SketchEntityId;
    readonly startPointId: SketchEntityId;
    readonly endPointId: SketchEntityId;
    readonly reversed: boolean;
}
```

`SketchProfile.id` 是 Resolver 单次计算生成的临时 id，只用于当前 UI 命中和渲染，不允许被特征长期引用。

## Profile Resolver

`SketchProfileResolver` 负责从草图实体中识别封闭区。

第一版能力：

1. 读取草图点和直线。
2. 按容差合并重合端点。
3. 构建二维无向图。
4. 查找闭合 loop。
5. 计算 loop 面积、方向、centroid、bbox。
6. 区分外环和内环。
7. 输出可被渲染和特征选择消费的 `SketchProfile[]`。

第一版不处理：

- 相交但未打断的线。
- 自相交 loop。
- 曲线精确 Profile。
- 约束求解。
- 多草图跨平面 Profile。

中期增强：

- 线线相交自动 split。
- 圆、圆弧参与封闭区。
- 曲线采样 Profile 和精确边界并存。
- Profile 诊断信息，例如 open chain、duplicate edge、self intersection。

## Profile Selection

特征引用的是用户选择的 Profile，而不是 Resolver 当前生成的 Profile id。

```ts
interface SketchProfileSelection {
    readonly sketchId: SketchId;
    readonly seedPoint: Vec2;
    readonly boundaryEntityIds: readonly SketchEntityId[];
    readonly innerBoundaryEntityIds: readonly SketchEntityId[][];
    readonly areaHint: number;
    readonly centroidHint: Vec2;
}
```

字段含义：

- `sketchId`：Profile 来源草图。
- `seedPoint`：用户点击封闭区时的草图局部坐标，用于区分共享边区域。
- `boundaryEntityIds`：当时外环边界实体集合。
- `innerBoundaryEntityIds`：当时洞边界实体集合。
- `areaHint` / `centroidHint`：重算匹配时的辅助信息。

匹配策略：

1. 草图变化后重新运行 `SketchProfileResolver`。
2. 优先匹配外环实体集合相同的 Profile。
3. 如果存在多个候选，用 `seedPoint` 判断落在哪个 Profile 内。
4. 如果实体集合变化但 `seedPoint` 仍落在唯一 Profile 内，可按策略自动跟随。
5. 如果无法唯一匹配，依赖该 Profile 的特征进入 broken 或待修复状态。

典型变化处理：

- 移动边线但区域仍封闭：Profile 自动更新，特征继续有效。
- 删除边线导致区域开放：匹配失败，特征 broken。
- 新增一条线把区域切成两块：`seedPoint` 落在哪块，特征跟随哪块。
- 两个区域合并：可用 `seedPoint` 自动跟随合并区域，也可以根据产品策略要求用户确认。

## 与特征建模的关系

拉伸、切除、旋转等特征不直接消费 `SketchProfile` 对象本身，而是保存 `SketchProfileSelection`。

```ts
interface ExtrudeFeaturePayload {
    readonly profile: SketchProfileSelection;
    readonly operation: 'new-body' | 'add' | 'cut';
    readonly distance: number;
}
```

重算流程：

1. 根据 `profile.sketchId` 找到草图。
2. 运行 Profile Resolver 得到最新 Profile 列表。
3. 使用 `SketchProfileSelection` 匹配当前 Profile。
4. 匹配成功后把 Profile 边界转换为 Wasm/OCCT 可消费的二维轮廓。
5. 匹配失败则特征标记为 broken，不生成错误几何。

## 编辑命令

中期命令优先级：

1. 进入/退出草图。
2. 直线绘制。
3. 草图实体选择。
4. 删除点/线。
5. 移动点。
6. Profile hover 和选择。
7. 矩形。
8. 圆。
9. 圆弧。
10. 多段线。

命令职责：

- `editor` 负责解释鼠标、键盘和工具状态。
- 临时预览进入 `EditDraft`。
- 正式修改通过 `DocumentOperation` 或草图状态更新进入文档。
- 命令层不手写几何投影，屏幕到草图平面转换必须复用统一投影链路。

## 渲染与拾取

草图显示分三类：

- 正式实体：点、线、圆弧等。
- 临时预览：当前命令未确认的线段、矩形、圆等。
- Profile 高亮：可用于特征建模的封闭区。

Profile 渲染规则：

- hover 时半透明填充。
- selected 时更明显填充和边界高亮。
- Profile 填充由 `cad-rendering` 从草图局部坐标投影到世界坐标。
- `webgl-engine` 只负责绘制面片、线段、点和返回命中结果。

Profile 拾取规则：

1. 先用 WebGL 或屏幕空间拾取获得候选。
2. 屏幕点投影到草图平面，得到 `seedPoint`。
3. 用 `Containment.pointInPolygon2` 判断点在哪个 Profile 内。
4. 多个 Profile 重叠时按面积、深度和选择优先级排序。

## 约束与尺寸

约束系统属于 `constraints` 包，不直接塞进 `sketch` 基础模型。

`sketch` 提供：

- 实体 id。
- 点、边、曲线引用。
- 草图局部坐标。
- Profile 解析结果。

`constraints` 提供：

- 几何约束数据模型。
- 尺寸约束数据模型。
- 求解输入输出。
- 对草图实体位置的更新建议。

约束求解落地前，草图实体编辑仍应保持自由绘制可用。

## 实施阶段

### 阶段 1：草图基础补齐

- 进入和退出草图稳定。
- 直线绘制稳定。
- 正式草图点线进入文档或稳定草图状态。
- 草图点线可选择、删除、移动。

### 阶段 2：Profile Resolver v1

- 支持直线闭合区识别。
- 支持多个独立封闭区。
- 支持外环和洞的基础判断。
- Profile 可渲染、hover、选择。
- 输出 `SketchProfileSelection`。

### 阶段 3：特征引用接入

- Extrude feature 保存 `SketchProfileSelection`。
- 草图修改后 Profile 重新匹配。
- 匹配失败的特征进入 broken 状态。
- 第一版只打通拉伸数据流，不在 TypeScript 实现 B-Rep。

### 阶段 4：草图工具扩展

- 矩形。
- 圆。
- 圆弧。
- 多段线。
- Profile Resolver 支持曲线采样级识别。

### 阶段 5：约束和尺寸

- 水平、垂直、重合、平行、垂直、相等。
- 线长、点距、角度、半径、直径。
- 约束求解器与草图实体更新闭环。

## 当前优先级

下一步应优先实现 `SketchProfileResolver` 的直线版本，并把 Profile 高亮接入渲染。这样后续拉伸可以直接基于 `SketchProfileSelection` 建立稳定引用，不需要在特征建模阶段回头重构草图数据模型。
