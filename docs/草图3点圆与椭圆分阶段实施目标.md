# 草图 3 点圆与椭圆分阶段实施目标

本文用于后续分阶段复制给 Codex 执行。

目标功能参考 Onshape 草图交互：

- 3 点圆：依次点击 3 个圆周点，第 3 点完成圆。
- 椭圆：依次点击长轴第一端、长轴第二端、短轴高度点，第 3 点完成椭圆。

当前项目已经实现中心点圆。本轮建议先补 3 点圆底层能力，再优先修复圆类曲线的整曲线选择/删除语义，然后接 3 点圆 UI，最后实现椭圆。

执行原则：

- 不改变现有 package 分层和 workspace package 依赖关系时，可以直接实施。
- 如果实施中发现必须新增/删除 workspace package 依赖、改变 package 分层，或需要高风险 public API 破坏性调整，先暂停并说明风险、影响范围和原因，等待确认。
- 当前中心点圆已经存在“只能选中采样小段”的问题，因此整曲线选择/删除不是最终收尾项，应该在新增 3 点圆 UI 前优先解决。

## 阶段 1：实现 3 点圆的模型与 Request

```txt
目标：在 occt-draw-web 中实现草图 3 点圆的底层模型能力和 DocumentRequest，不改 UI 命令入口。

包职责与边界：
- packages/math：在 Circle2 上新增三点外接圆静态构造方法，例如 Circle2.fromThreePoints(first, second, third, tolerance?)。
- packages/sketch：新增 SketchPrimitiveBuilder.addCircleThroughPoints(first, second, third)，但只调用 Circle2.fromThreePoints 并创建 Circle2D，不在 builder 中实现外接圆公式。
- packages/cad-model：新增 AddThreePointCircleRequest，通过 CadDocumentWriteContext 的 SketchWriteTarget.primitives 调用 addCircleThroughPoints。
- 不修改 DocumentEditor、MutationScope、Transaction、History。
- 不新增 workspace package 依赖；packages/sketch 可以使用已有的 @occt-draw/math 依赖。

实现要求：
1. 在 packages/math/src/geometry-2d/circle2.ts 中实现 Circle2.fromThreePoints(...)。
2. Circle2.fromThreePoints 负责纯几何计算和退化判断：
   - 任意两点距离过小返回 null。
   - 三点近共线返回 null。
   - 半径非法返回 null。
   - 正常返回 Circle2。
3. SketchPrimitiveBuilder.addCircleThroughPoints(...) 只负责：
   - 调用 Circle2.fromThreePoints。
   - 分配 curveId。
   - 创建 Circle2D。
   - 加入 sketch.entities.geometry.curves。
4. 新增 request result 类型，返回 createdCurveId、payloadId、partStudioId、sketchFeatureId。
5. AddThreePointCircleRequest 和 AddThreePointCircleRequestResult 从 @occt-draw/cad-model public entry 导出，editor 后续只能从 public entry import。
6. 保持 change recording 走现有 SketchPrimitiveBuilder recorder 机制。
7. 实现自检：
   - 正常三点：AddThreePointCircleRequest 通过 DocumentEditor.execute 后生成 Circle2D，undo/redo 走现有 DocumentSession/Transaction 链路。
   - 退化三点：AddThreePointCircleRequest 返回 createdCurveId: null，不新增 Circle2D；因为不调用 curves.add，不应记录 sketch change，最终 empty transaction 不进入 history。
8. 运行 pnpm check。
```

## 阶段 2：实现圆类曲线的整曲线选择和删除

```txt
目标：让当前中心点圆以及后续 3 点圆、椭圆在草图内像 Onshape 一样按整条曲线选择和删除，而不是只能选中采样出来的一小段。

包职责与边界：
- packages/sketch：让 SketchPrimitiveBuilder.deleteEntity 支持 SketchEntityKind.Curve，删除整条 curve。
- packages/cad-model：让 DeleteSketchEntityRequest 的可编辑实体判断支持 Curve ref；不改事务主链路。
- packages/cad-canvas：让拾取 sampled curve segment 时返回其所属 Curve ref；预选/选中高亮覆盖同一 curve 的全部 sampled segments。
- packages/editor：确认选择状态、删除命令、undo/redo 能处理 Curve ref。
- 不修改 DocumentEditor、MutationScope、Transaction、History。
- 不新增 workspace package 依赖。

实现要求：
1. 拾取 Circle2D 的任意 sampled segment 时，选中的实体必须是整条 SketchEntityKind.Curve。
2. 预选/选中高亮必须覆盖同一 curve 的全部 sampled segments，不能只高亮单个 segment。
3. Delete 删除选中的 curve 时，必须删除整个圆。
4. 线段 edge、vertex 的既有选择、预选、高亮、删除行为不能退化。
5. 优先复用现有 selection target 类型；如果必须新增 curve selection target、改变 RenderHighlightState，或改变跨包 public API，先暂停说明原因、影响范围和风险。
6. isEditableSketchEntityRef 支持 Curve。
7. SketchPrimitiveBuilder.deleteEntity 支持删除 Curve，并通过 recorder 记录删除。
8. DeleteSketchEntityRequest 删除 Curve 后，整条圆消失，undo/redo 正常恢复。
9. 使用内置浏览器验证：
   - 绘制中心点圆。
   - 点击圆任意位置，整条曲线被选中并整体高亮。
   - Delete/Backspace 删除整条曲线。
   - undo/redo 删除操作正常。
   - 线段/顶点选择和删除仍正常。
10. 运行 pnpm check。
```

## 阶段 3：实现 3 点圆交互命令与工具栏入口

```txt
目标：在草图工具栏中加入“3 点圆”，交互行为对齐 Onshape：依次点击 3 个圆周点，第 3 点提交圆。

包职责与边界：
- packages/editor：新增 SketchThreePointCircleCommand，扩展 CommandId、SketchToolState、commandRegistry、ViewportInteractionController。
- apps/web：在 CommandToolbar 的圆工具组加入 3 点圆入口，使用 ToolbarIconId.Circle3Point。
- packages/ui：检查 toolbar-icons.svg 是否已有 cad-toolbar-icon-circle-3-point；如没有，则新增项目自有 3 点圆 SVG symbol。
- 不修改 core/cad-model 事务主链路。
- 不新增 workspace package 依赖；如只复用 apps/web 已有的 @occt-draw/ui 依赖，不视为依赖关系变化。

实现要求：
1. 新增 command id：sketch-3-point-circle。
2. SketchToolState 增加 three-point-circle 状态，保存 firstPoint、secondPoint。
3. 交互状态：
   - 第一次点击记录 firstPoint。
   - 第二次点击记录 secondPoint。
   - pointer move 时基于当前点显示圆预览。
   - 第三次点击提交 AddThreePointCircleRequest。
4. editor 只从 @occt-draw/cad-model public entry import AddThreePointCircleRequest。
5. draft 预览复用 sampleSketchCurveSegments({ kind: 'circle', center, radius })。
6. Escape/cancel 行为与 SketchCircleCommand 一致。
7. 工具栏圆组包含：中心点圆、3 点圆。
8. 图标要求：
   - 图标语义对齐 Onshape 的 3 点圆：一个圆形轮廓，并突出圆周上的 3 个定义点。
   - 必须使用项目自有 toolbar icon sprite，不复制 Onshape 图标资源。
   - 如果 packages/ui/src/assets/toolbar-icons.svg 已有 cad-toolbar-icon-circle-3-point，则直接复用。
   - 如果不存在，则新增自有 SVG symbol，线宽、viewBox、stroke/currentColor 风格与现有 toolbar icon 保持一致。
9. 使用内置浏览器验证：进入草图 -> 选择 3 点圆 -> 点 3 个圆周点 -> 生成圆 -> 选中整圆 -> undo/redo 正常。
10. 运行 pnpm check。
```

## 阶段 4：新增 Ellipse2D 模型、序列化与显示采样

```txt
目标：为 sketch 包新增可旋转椭圆曲线模型 Ellipse2D，但暂不接 UI 命令。

包职责与边界：
- packages/math：将 Ellipse2 升级为基于 Coord2 局部坐标系的椭圆曲线，支持任意方向椭圆；保留 Ellipse2.fromAxisPoints(firstAxisPoint, secondAxisPoint, minorPoint)，并新增 Ellipse2.fromCenterAxisPoints(centerPoint, primaryAxisPoint, secondaryPoint) 作为 Onshape 风格构造 helper。
- packages/sketch：新增 Ellipse2D、Ellipse2DSnapshot、curveFromSnapshot 支持、sampleSketchCurveSegments 支持椭圆。
- packages/sketch：Ellipse2D 复用 math.Ellipse2 的 Coord2 局部坐标系和采样能力，不在 sketch 层重复实现旋转椭圆几何算法。
- packages/cad-canvas：原则上不需要改，继续使用 SketchDisplayBuilder 的 sampledCurveEdges。
- 不修改 editor/cad-model 命令。
- 允许按长期正确模型对 Ellipse2 做破坏性 API 调整；不要求保留旧 constructor 兼容，只要求同步修正现有调用并确保功能不受影响。
- 不新增 workspace package 依赖。

实现要求：
1. 扩展 packages/math/src/geometry-2d/ellipse2.ts：
   - Ellipse2 使用 Coord2 + majorRadius + minorRadius 表达椭圆。
   - Coord2.origin 表示椭圆中心。
   - Coord2.xAxis 表示长轴方向。
   - Coord2.yAxis 表示短轴方向。
   - pointAt(t) 使用 coord.localToWorld({ x: cos(t) * majorRadius, y: sin(t) * minorRadius })。
   - tangentAt(t)、bounds()、isValid() 同步基于 Coord2 实现。
   - 可以破坏性调整 constructor/API；同步修正现有调用，保证现有功能不受影响。
   - 保留 Ellipse2.fromAxisPoints(firstAxisPoint, secondAxisPoint, minorPoint)。
   - 新增 Ellipse2.fromCenterAxisPoints(centerPoint, primaryAxisPoint, secondaryPoint)。
   - 退化输入返回 null：主轴过短、副轴过短、坐标非法。
2. 在 Sketch types 中新增 Ellipse2DSnapshot：
   - kind: 'ellipse'
   - id
   - center
   - xAxis
   - yAxis
   - majorRadius
   - minorRadius
   - center/xAxis/yAxis 是 Ellipse2D 的 Coord2 序列化字段，不额外保存 rotationRadians，也不重复保存 coord 对象。
3. Curve2DSnapshot 联合类型加入 ellipse。
4. geometry.ts 新增 Ellipse2D extends Curve2D。
5. Ellipse2D 支持 snapshot/fromSnapshot/ref，并能转换为 math.Ellipse2。
6. @occt-draw/sketch public entry 导出 Ellipse2D、Ellipse2DSnapshot，以及必要的采样输入类型。
7. curveFromSnapshot 支持 ellipse。
8. curveSampling.ts 对 Ellipse2D 调用 math.Ellipse2 采样。
9. SketchDisplayBuilder 不应需要特殊分支，确认 sampledCurveEdges 能显示 ellipse。
10. 实现自检：Ellipse2D 能 snapshot/fromSnapshot，采样结果能显示为闭合椭圆。
11. 运行 pnpm check。
```

## 阶段 5：实现椭圆 Request 与 PrimitiveBuilder 写入能力

```txt
目标：实现 Onshape 风格椭圆底层创建能力：中心点、主轴半径点、副轴半径点。

包职责与边界：
- packages/sketch：新增 SketchPrimitiveBuilder.addEllipseByCenterAxes(centerPoint, primaryAxisPoint, secondaryPoint)，保留 addEllipseByAxis 以便已有底层构造能力继续可用。
- packages/cad-model：AddEllipseRequest 接收 centerPoint、primaryAxisPoint、secondaryPoint。
- 不修改 DocumentEditor、MutationScope、Transaction、History。
- 不新增 workspace package 依赖。

实现要求：
1. SketchPrimitiveBuilder.addEllipseByCenterAxes 不实现几何公式，只调用 Ellipse2.fromCenterAxisPoints(...)。
2. Ellipse2.fromCenterAxisPoints 返回 null 时，addEllipseByCenterAxes 返回 null。
3. Ellipse2.fromCenterAxisPoints 返回 Ellipse2 时，创建 Ellipse2D 并加入 sketch.entities.geometry.curves。
4. AddEllipseRequest 只调用 target.primitives.addEllipseByCenterAxes。
5. AddEllipseRequest 和 AddEllipseRequestResult 从 @occt-draw/cad-model public entry 导出，editor 后续只能从 public entry import。
6. 实现自检：正常三点生成 ellipse；退化输入不生成 ellipse。
7. 运行 pnpm check。
```

## 阶段 6：实现椭圆交互命令与工具栏入口

```txt
目标：在草图工具栏中加入“椭圆”，交互行为对齐 Onshape：点击中心点、主轴半径点、副轴半径点，第 3 点提交椭圆。

包职责与边界：
- packages/editor：新增 SketchEllipseCommand，扩展 CommandId、SketchToolState、commandRegistry、ViewportInteractionController。
- apps/web：在圆工具组加入椭圆入口，使用 ToolbarIconId.Ellipse。
- packages/ui：检查 toolbar-icons.svg 是否已有 cad-toolbar-icon-ellipse；如没有，则新增项目自有椭圆 SVG symbol。
- 不修改 core/cad-model 事务主链路。
- 不新增 workspace package 依赖。

实现要求：
1. 新增 command id：sketch-ellipse。
2. SketchToolState 增加 ellipse 状态：
   - centerPoint: Vector2 | null
   - primaryAxisPoint: Vector2 | null
3. 交互状态：
   - 第一次点击记录 centerPoint。
   - 第一次 pointer move 用中心点到 cursor 生成等半径临时椭圆/圆预览，显示中心点。
   - 第二次点击记录 primaryAxisPoint。
   - 第二次 pointer move 用 secondary point 到主轴垂线方向投影生成椭圆预览，显示中心点和主轴点。
   - 第三次点击提交 AddEllipseRequest。
4. editor 只从 @occt-draw/cad-model public entry import AddEllipseRequest。
5. draft 预览使用椭圆采样段，并转成 temporary line-segment objects；采样线段设置 showEndpointPoints: false，只额外渲染已确认的定义点，不显示尺寸文本。
6. 工具栏圆组包含：中心点圆、3 点圆、椭圆。
7. 图标要求：
   - 图标语义对齐 Onshape 的椭圆工具：显示倾斜或轴向明确的椭圆轮廓，并体现由长轴/短轴定义椭圆的语义。
   - 必须使用项目自有 toolbar icon sprite，不复制 Onshape 图标资源。
   - 如果 packages/ui/src/assets/toolbar-icons.svg 已有 cad-toolbar-icon-ellipse，则直接复用。
   - 如果不存在，则新增自有 SVG symbol，线宽、viewBox、stroke/currentColor 风格与现有 toolbar icon 保持一致。
   - 椭圆图标应与中心点圆、3 点圆在同一圆/椭圆工具组中视觉区分明确，避免看起来像普通圆。
8. Escape/cancel 行为与 SketchCircleCommand 风格一致：
   - 有部分输入时清空当前 ellipse 输入，仍停留在 ellipse 工具。
   - 无输入时退出到 select。
9. 使用内置浏览器验证：进入草图 -> 选择椭圆 -> 点 3 点 -> 生成椭圆 -> 选中整个椭圆 -> undo/redo 正常。
10. 运行 pnpm check。
```
